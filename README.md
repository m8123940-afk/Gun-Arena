# Rival Arena — 1v1 шутер в стиле Rivals

- `client/index.html` — вся игра в одном файле (Three.js с CDN).
- `server/server.js` — онлайн: матчмейкинг, комнаты, HP и раунды (до 5 побед) на сервере, проверка урона/скорострельности/дистанции.

## Запуск
```
cd server
npm install
npm start
```
Открой `http://localhost:3000` в двух вкладках/на двух компьютерах и нажми «ОНЛАЙН ДУЭЛЬ».
Для друзей в интернете: запусти сервер на VPS (Render/Fly/Railway), укажи его адрес `wss://...` в поле «Сервер».
Без сервера работает «Тренировка с ботом» (достаточно открыть index.html).

## Управление
WASD, Пробел — прыжок (зажми для банихопа), Shift/C — слайд (слайд + прыжок сохраняет скорость), ЛКМ — огонь, ПКМ — прицел снайперки, R — перезарядка, 1/2/3 — слоты, Q — нож.

## Форматы
1v1, 2v2, 5v5 и FFA (выбор: кнопка «ДРУГИЕ»). Офлайн недостающие места занимают боты. Онлайн сервер ставит игроков в очередь нужного формата и стартует, когда набралось нужное число людей или через 15 секунд, если собралось минимум двое. Команды 2v2/5v5 делятся поровну по очереди, в FFA каждый сам за себя; раунды идут до 5 побед.
